# 집밥요정

<!-- 나중에: 서비스 한 줄 소개, 주요 기능, 스크린샷 -->

냉장고 속 재료로 집밥 레시피를 추천하는 웹 서비스입니다.

## 기술 스택

- 프론트엔드: HTML / CSS / JavaScript
- 백엔드: Vercel Serverless Functions (Python)
- AI: Google Gemini

## 시작하기

<!-- 나중에: 로컬 실행(Vercel CLI), `.env` 설정, 배포 절차 -->

1. 저장소를 클론합니다.
2. `.env`에 Gemini API 키를 넣습니다.
3. 프론트엔드를 브라우저에서 열고 API를 연결합니다.

## 폴더 구조

```
index.html          # 메인 페이지
css/style.css       # 스타일
js/main.js          # 프론트엔드 로직
api/recommend.py    # 레시피 추천 API
requirements.txt    # Python 의존성
```
